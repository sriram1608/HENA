# HENA Saree Studio 🌸
> *"Your Style, Your Saree"* — Luxury Handloom, Soft Silk, Paithani, and Festive Designer Sarees.

A modern, responsive e-commerce web application built for **HENA Saree Studio**, inspired by contemporary South Indian boutique aesthetics.

## ✨ Features
- **Hero Carousel Banner:** High-definition auto-playing image slider highlighting seasonal collections and festive campaigns.
- **Left-Aligned Brand Navigation:** Circular boutique logo, quick-access category mega-dropdown, and sticky blur header.
- **36+ Handcrafted Sarees Catalog:** Categorized into Kanchi Soft Silk, Semi Banarasi, Paithani, Premium Kanchipuram, Designer Sarees, and Temple Antique Jewellery.
- **Interactive Shopping Experience:**
  - Dynamic category tabs and instant price/popularity sorting.
  - Interactive Quick View modal with multi-angle image previews and fabric specifications.
  - Wishlist drawer with instant save/remove functionality.
  - Cart drawer with live price calculation, free shipping progress bar, and promo coupon support (`HENA10`).
  - COD & Prepaid mock checkout system with order confirmation numbers.
- **Customer Reviews & Ratings:** Verified buyer testimonials with star ratings and photos.
- **WhatsApp Direct Connect:** Floating chat button and pre-filled consultation links for styling guidance and video shopping.
- **Zero Build Tools / Zero Node.js Dependency:** Built with React 18 & Babel Standalone running entirely client-side via CDN. Opens directly in any browser!

## 🚀 Quick Start
Simply open `index.html` in your web browser:
```bash
# Windows
start index.html

# Mac
open index.html

# Linux
xdg-open index.html
```
